STR
CLIENT SERVER STATE
i

As funções de dados, economia, inventário e identidade são server-side. No client, use os helpers de tunnel para chamar funções registradas no server. As funções listadas refletem as definições encontradas em Str.lua e client.lua; módulos podem adicionar statebags próprios.

REFERÊNCIA DA API

Str.functions

Pesquise por nome ou finalidade. Cada assinatura mostra os argumentos aceitos e o formato do retorno.

Chamadas server-side: Str.functions.nome(...). Também são registradas como exports pelo núcleo. Argumentos que identificam personagem devem vir de contexto confiável do servidor.

O client expõe helpers para o tunnel. Use syncTunnelFunction para obter os valores de retorno da função registrada no server; asyncTunnelFunction dispara sem aguardar resposta.

Nenhuma função corresponde à busca.

DADOS REATIVOS

Statebags

Chaves de estado publicadas pelo núcleo e pelos módulos presentes neste workspace.

Leia estado de jogador por Player(source).state.chave no server ou LocalPlayer.state.chave no client. Para entidades, use Entity(entity).state.chave. A flag replicated controla se a alteração é replicada; true não substitui a validação de dados no server.

-- Client: observar uma mudança replicada no jogador local
AddStateBagChangeHandler('health', nil, function(bagName, key, value)
    if bagName == ('player_' .. GetPlayerServerId(PlayerId())) then
        print(('Novo %s: %s'):format(key, value))
    end
end)

Chaves temporárias de cache e fila do núcleo que são limpas durante a inicialização não são tratadas como API pública estável. Consulte o código do módulo antes de depender de statebags específicos de uma extensão.

Exemplos práticos

Os comentários mostram o retorno esperado para os valores de exemplo.

SERVERIdentidade e saldo
local characterId = Str.functions.getCharacterId(source)
if not characterId then return end

local balance = Str.functions.getCharacterMoneyAmount(
    characterId, 'cash'
)
print(balance)
-- Exemplo de retorno: 125

local added = Str.functions.addCharacterMoney(
    characterId, 25, 'cash'
)
print(added)
-- Exemplo de retorno: true
SERVERInventário
local item = Str.functions.getItemFromCharacterInventory(
                            characterId, 'backpackS'
)
print(json.encode(item))
-- Exemplo de retorno:
                        -- {"name":"backpackS","amount":1}
CLIENTConsultar config no server
local items = Str.functions.syncTunnelFunction(
    'getItemsConfig'
)
print(type(items))
-- Exemplo de retorno: "table"
print(items.backpackS.label)
-- Exemplo de retorno na configuração atual: "Backpack pequena"
SERVERVerificar grupo
local level = Str.functions.hasCharacterGroup(
                            characterId, 'Staff'
)
print(level)
                        -- Exemplo de retorno: 3 (nível do grupo)

local hierarchy, name =
    Str.functions.getCharacterGroupHierarchy(
                                characterId, 'Staff'
    )
print(hierarchy, name)
                        -- Exemplo de retorno: 3, "Admin"
